# FeedMeDaily v0.7.1

## 更新

- RSC 邮件提醒生成的 RSS 可按 DOI 拆分为独立论文，并过滤账户和确认邮件。
- 新安装默认在每天本地时间 09:00 自动同步；已有定时设置保持不变。
- 安装完成后可直接打开托盘和网页；桌面图标在托盘未运行时启动托盘，运行时打开网页。
- 订阅目录搜索支持一键清空，定向同步的已选期刊更容易查看和移除；期刊筛选列表可显示更多条目。
- 暂时隐藏新增邮件订阅入口；已有邮件订阅仍可查看和移除。
- 修复首次设置时已有 API key 仍提示缺失、同一供应商的另一模型被误判为缺少 key 的问题，并移除过时的 Profile 设置项。
- 同步遇到短暂网络故障时会自动补试；数据库清理的停止按钮移到启动按钮旁。
