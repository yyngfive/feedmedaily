# FeedMeDaily v0.6.0

## 更新

- 支持切换分类模型，支持：DeepSeek V4 Flash、GLM-5.3-Flash、Qwen3.8-Flash、MiMo-V2.5，支持开启最低档位思考模式
- 新增任务费用统计并可手动修改价格
- Sync和Reclassify任务可以随时取消
- 修复了同步和重分类可以多次重复提交的BUG
- 优化了重分类功能，支持自定义数量，支持更广的分类范围
- 优化了设置页UI
- 每日同步的默认时间调整为12:30（DeepSeek 低谷时段）

## 已知问题

- RSS 目录可能存在链接错误或缺失
- 模型开启思考模式后可能容易导致分类整批次失败
