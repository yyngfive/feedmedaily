# FeedMeDaily v0.6.0

## 更新

- 新增多分类模型管理：DeepSeek V4 Flash、GLM-5.3-Flash、Qwen3.8-Flash、MiMo-V2.5 每模型独立密钥、连接测试与默认模型选择
- 新增分类思考开关（Advanced）：仅启用各供应商最低档思考，GLM 固定为 low；分类批次大小默认降为 5
- 新增任务费用统计：按任务估算 DeepSeek/GLM 用量与成本，Dashboard 显示最近任务费用和近三天用量，可手动微调定价
- 新增 Stop sync：手动同步可随时停止，已写入数据与已完成批次保留，活动面板显示停止前的完成量与警告
- 重分类重构：今天、Feedback、全部、指定数量、仅未分类五种范围，确认前显示已分类/未分类预览，运行中可随时停止
- 应用 Profile proposal 的反馈重分类改为后台任务：不阻塞页面，可与同步互斥排队，随时停止
- 同步与重分类互斥执行：同一时刻只有一个分类任务运行，手动重复启动会被拒绝或复用现有任务
- 取消任务保留部分结果：取消后的同步/重分类显示已完成数量而不是全部清零，重跑自动跳过已分类文章
- 设置抽屉重构：稳定的侧边导航与文档式页面，Dashboard 优先展示运行中任务，模型页整合连接、调优与定价
- 每日同步时间调整为本地 12:30（DeepSeek 低谷时段）
